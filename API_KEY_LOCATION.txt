API KEY CONFIGURATION — SECURITY NOTICE

Do not store API keys in source files, documentation, screenshots, or Git history.

Configure the Gemini API key through the deployment platform's encrypted environment-variable settings:
  GEMINI_API_KEY=<your-new-key>

For local development, create a local .env file from .env.example. Keep .env out of Git.
Never print API key values in logs or documentation.

IMPORTANT: A Gemini API key was previously committed in this repository's public files and Git history.
Treat that key as compromised and revoke/rotate it in the provider console immediately.
Removing it from the current files does not erase it from existing Git history or public caches.

Flask debug mode defaults to disabled. Set FLASK_DEBUG=true only for local development, never for production.
